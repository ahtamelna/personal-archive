PUT YOUR ACTUAL ARCHIVE FILES HERE

Examples:
archive/example.pdf
archive/photo.jpg
archive/notes.txt
archive/video.mp4

After adding a file to this folder and pushing to GitHub, open the website's
Admin -> Archive files -> Add file/record and enter the same repository path.

Important: files in a public GitHub repository are public. The website's
Public/Private switch controls whether the Firestore archive record appears
on the site; it does NOT make a GitHub file private.

For genuinely private files, use a private file provider such as a restricted
Google Drive file and enter its direct URL in the archive record instead of a
GitHub path. Do not put private credentials or API tokens in index.html.
